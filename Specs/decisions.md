# Журнал решений и отчёт

Решения, принятые автономно (пользователя не было, вопросы не задавались):

1. orders.json в задании не приложен к спецификации; восстановлен по ожидаемому результату: 101 (1500, paid), 102 (2000, pending), 103 (3000, paid), 104 (0, paid) -> 3 / 4500 / №103 / paid 3, pending 1.
2. Корень `{}` при `json_decode(..., true)` даёт `[]`, который проходит `array_is_list`; добавлена проверка первого непробельного символа `[` — иначе `{}` ошибочно считался бы пустым списком.
3. Запись `[]` или список вместо объекта — «запись не является объектом».
4. «Распознанная сумма» в пропущенных = сумма записей с валидным amount (у дубликатов — их сумма).
5. Вывод в `data/*.json` подобран под каждый сценарий из раздела 3 спецификации.
6. Git: репозиторий инициализирован, коммиты не делались/пуш не выполнялся (раздел 12: push — автор). См. отчёт.
7. Различие вывода локально/Docker — только CRLF vs LF (PHP_EOL на Windows).
